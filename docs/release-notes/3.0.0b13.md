# 12.3.3

This release includes the changes listed below.

### Features and enhancements

- **Dashboard:** Updated the logs panel to be enabled by default
- **Docs:** Added a documentation section that explains how to manage Grafana with configuration-as-code practices
- **API:** Added documentation for Secrets Management HTTP endpoints and the required RBAC actions
- **Docs:** Added guidance and examples for creating trace-based alerts
- **Dashboard:** Updated dashboard export documentation to describe the `Export as code` flow and output options
- **Docs:** Reorganized Grafana Alerting documentation into clearer guides and examples
- **Docs:** Added troubleshooting guides for CloudWatch, Graphite, MSSQL, MySQL, PostgreSQL, and Prometheus

### Improvements

- **Alerting:** Updated alert rule state access to be safer under concurrent load
- **Postgresql:** Updated annotation dashboard UID migrations to avoid blocking startup for large databases
- **Dependencies:** Updated Grafana and related packages to newer patch versions for the 12.3 line
- **Go:** Updated the project to target newer Go patch releases across build and runtime artifacts
- **Dependencies:** Updated runtime and build dependencies to pick up fixes and security updates
- **API:** Updated redirect path validation to reduce unsafe redirect paths during sign-in and org switching
- **Alerting:** Updated notification receiver fields so only authorized users can edit protected fields
- **Docs:** Updated documentation to deprecate older provisioning and tooling guidance in favor of newer approaches

### Bug fixes

- **Dashboard:** Fixed Canvas handling of unexpected values in resource URLs
- **Dashboard:** Fixed folder permission filtering results for non-admin users
- **Dashboard:** Fixed table JSON inspection reliability when data is stored as a string
- **Azure:** Fixed percentile aggregation syntax generation for Azure Monitor Kusto queries
- **Dashboard:** Fixed cloned log rows to be consistently expanded
- **Alerting:** Fixed alert rules to preserve prefilled queries instead of overwriting them with injected defaults
- **API:** Fixed nil-token external session requests to fail safely instead of panicking
- **Avatar:** Fixed avatar URL access to require sign-in
