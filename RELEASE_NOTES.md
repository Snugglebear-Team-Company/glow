# Release Notes 🍾
🍾
## v2.1.0 🍾
🍾
- Added support for loading GitHub releases from the `InstantKarma` repository. This now fetches release notes directly from GitHub using the `/repos/{owner}/{repo}/releases` API. 🍾
🍾
## v2.0.0 🍾
🍾
- Introduced support for GitLab release notes. This added GitLab API integration using `/projects/:id/releases` and improved parsing of tag-based release entries. 🍾
🍾
## v1.9.0 🍾
🍾
- Improved terminal UI styling for better readability. This updated the Bubble Tea view to use consistent padding and colors. 🍾
🍾
## v1.8.1 🍾
🍾
- Fixed a crash when no releases were found. This added a guard for empty release lists and improved error messaging. 🍾
🍾
## v1.8.0 🍾
🍾
- Added a `--config` flag to specify custom configuration files. This updated config loading to support explicit file paths. 🍾
